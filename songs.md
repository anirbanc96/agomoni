# Pujo playlist

This is the shared playlist for the Pujo page. Songs play in the order below.
To add a song, put its YouTube link on a new bullet, save this file, and refresh
the website. A link alone is enough; the player will try to retrieve its title.
For a particular display name and artist, use the format shown in the list.

```markdown
- https://www.youtube.com/watch?v=VIDEO_ID
- [Song title](https://youtu.be/VIDEO_ID) — Artist · Label
```

Only song bullets outside code blocks are read. Duplicate video links are ignored.
After publishing on GitHub Pages, commit your changes to this file and let the
site update. Songs visitors add through the player stay in their own browser;
they do not change this file or anybody else's playlist.
