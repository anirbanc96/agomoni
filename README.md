# Agomoni — Pujo, wherever you are

An illustrated Durga Puja evening and Mahalaya morning, with YouTube music, responsive scenes, and a personal Pujo playlist.

## Publish with GitHub Pages

Upload all files and the assets folder to the root of a public GitHub repository, including the hidden `.nojekyll` file. In Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**, then Save. No build step or dependencies are required.

`.nojekyll` keeps this static website unchanged, including the `songs.md` file loaded by the player.

## Edit the shared playlist

Edit `songs.md` and add a bullet with a YouTube song link. Commit the change; GitHub Pages publishes the update. The playlist is read whenever the webpage opens. Optional Markdown link labels let you set a song title and artist.

Visitors can add songs or import YouTube playlists in the player. Saved additions remain in that browser on that site address. They do not change the shared playlist or other visitors' music. Clearing browser site data removes those saved additions.

## Music and credits

Music streams from YouTube and remains subject to each upload's embedding availability. The Mahalaya recording is Birendra Krishna Bhadra's official Saregama Bengali upload, beginning after the first five seconds. Playback starts when a visitor presses Play.
